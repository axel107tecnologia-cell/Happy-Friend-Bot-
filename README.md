# Friends Happy Bot

Bot de WhatsApp para Termux, desarrollado para uso personal y educativo.

## Funciones

- Descarga de videos y audios.
- Creación de stickers.
- Búsqueda de imágenes.
- Comandos de administración.
- Anti-link para enlaces no permitidos.
- Mensajes de bienvenida y despedida.
- Soporte para bot principal y sub-bots.

## Instalación

bash
git clone REPOSITORIO
cd Happy-Friend-Bot-
npm install
npm start

## Ejecutarlo en Termux

termux-wake-lock
tmux new -s friendsbot
npm start
